# HippoType 🦛⌨️

**HippoType** is a web-based typing practice application designed to improve **typing speed, accuracy, and consistency**.

### ✨ Features

* ⌨️ Multiple typing modes: **15s, 30s, 60s, 2m, 5m, Word & Zen**
* 🌐 Multiple languages: **English, Spanish, French, German & Stenography**
* 💻 Code typing practice: **C, C++, Python, Java & React**
* 📊 Real-time **WPM, accuracy, errors & combo** tracking
* 🎯 Adaptive difficulty
* 📝 Custom text typing
* 🏆 Achievements and statistics
* 🏅 Online leaderboard using **Google Sheets + Google Apps Script**
* 🔐 Login and signup system
* 🎨 Custom themes and font-size settings
* 🚨 Steno Funnel for high-speed multi-character input

### 🛠️ Technologies

* **HTML**
* **CSS**
* **JavaScript**
* **Google Apps Script**
* **Google Sheets**

### 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser.
4. Create an account and start typing.
